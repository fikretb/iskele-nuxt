# İskele Pro tanıtım sitesi

Yapı [Odoo](https://www.odoo.com/tr_TR) uygulama menüsü ve tanıtım dilinden: mega menü, uygulama ızgarası, sektör sayfası.

## Çalıştırma

```bash
npm install
npm run dev
```

http://localhost:3000

## Sayfalar

- `/` ana sayfa
- `/uygulamalar` tüm uygulamalar
- `/uygulamalar/:slug` uygulama detayı
- `/sektor` iskele kiralama
- `/fiyatlandirma`
- `/iletisim`

Giriş: `NUXT_PUBLIC_APP_URL`
